Prototype settings

  • Signed in as – switch user and role
  • Single enrolment journey – A (task list) or B (one question per page)
  • Simulate – PDS unavailable, supplier unavailable on submit, bulk file with no problems
  • Show session timeout warning – opens the MoJ timeout warning
  • Reset data (footer) – puts all test data back to the start

Patterns used

NHS design system first; X-GOV patterns (rebuilt with NHS styles) only where NHS has no fit. Each page template starts with a comment listing its ticket and patterns.

  • X-GOV (MoJ): Organisation switcher, Identity bar, Timeline, Filter a list, Add to a list, Add another, Spinner, Numeric data, Notification badge, Page header actions, Timeout warning
  • X-GOV (GOV.UK): Passwords, There is a problem with the service, Recover from validation errors, Accessible autocomplete
  • Changed from the backlog: NHS sortable tables instead of MoJ Sortable table (now built into NHS Frontend); NHS Interruption page (confirmation example) instead of MoJ Confirm an action; NHS header navigation instead of GOV.UK Service navigation
